# Security

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/PascalA94/Umbraco.Community.PackageCheck/security/advisories/new), not in a public issue.

PackageCheck downloads and reads third-party packages, so reports about crafted packages (archive tricks, oversized entries, malformed assemblies, text that injects into a report or terminal) are especially welcome. Only the latest release is supported.
